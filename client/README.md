# TaskFlow Frontend Client

Modern Agile Task & Workspace Management Single Page Application (SPA) built with **React 19**, **Vite**, **Material UI (MUI v9)**, and **Redux Toolkit**.

## Tech Stack
- **Framework**: [React 19](https://react.dev/) + [Vite](https://vitejs.dev/)
- **UI Components & Theme**: [Material UI (MUI v9)](https://mui.com/) + Emotion
- **State Management & Data Fetching**: [Redux Toolkit](https://redux-toolkit.js.org/) & RTK Query
- **Routing**: [React Router DOM v7](https://reactrouter.com/)
- **Real-Time Client**: [Socket.IO Client](https://socket.io/)
- **Internationalization**: [i18next](https://www.i18next.com/) & [react-i18next](https://react.i18next.com/) with RTL support via `stylis-plugin-rtl`

## Getting Started

### 1. Copy Environment Variables
```bash
cp .env.example .env
```

### 2. Install Dependencies
```bash
npm install
```

### 3. Run Development Server
```bash
npm run dev
```
The application will be available at `http://localhost:5173`.

### 4. Build for Production
```bash
npm run build
npm run preview
```
